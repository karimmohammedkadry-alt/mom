هدية ماما — نسخة الصور ❤️

تشغيل محلي:
1. فك الضغط.
2. افتح index.html في المتصفح.

نشره كرابط على الإنترنت (مجاني باستخدام GitHub Pages):
1. ادخل github.com وسجّل الدخول.
2. أنشئ Repository جديدًا باسم mom-gift (اجعله Public).
3. ارفع index.html ومجلد images كاملًا إلى جذر المستودع.
4. افتح Settings > Pages.
5. من Build and deployment اختر Deploy from a branch.
6. اختر branch: main والمجلد: /(root)، ثم Save.
7. انتظر قليلًا وسيظهر رابط الموقع داخل صفحة Pages.

مهم: لا ترفع صورًا شخصية إلى مستودع عام إلا إذا كنت موافقًا على أن أي شخص معه الرابط يستطيع رؤيتها.
لتعديل الرسالة افتح index.html في VS Code وابحث عن قسم <section id="letter">.
